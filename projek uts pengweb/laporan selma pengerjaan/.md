### Proses Pengerjaan Projek UTS

Dalam mengerjakan projek UTS ini, tahap pertama yang saya lakukan adalah menentukan tema website yang ingin dibuat. Saya memilih tema parfum dengan nama **LAVERA** karena saya menyukai berbagai macam aroma parfum dan tertarik untuk membuat website yang berisi katalog parfum wanita dan pria.

Setelah menentukan tema, saya mulai membuat kerangka website terlebih dahulu. Saya merencanakan beberapa halaman yang akan dibuat, yaitu Home, About, Product, dan Registration. Setelah itu, saya mulai menyusun bagian-bagian website menggunakan HTML.

Pada awal pengerjaan, saya sempat mengalami kesulitan dalam menghubungkan beberapa file HTML agar setiap halaman bisa saling terhubung melalui menu navigasi. Karena sebelumnya saya belum terlalu memahami cara kerjanya, saya mencoba meminta penjelasan dari AI agar lebih mengerti bagaimana cara membuat dan menghubungkan halaman-halaman tersebut.

Setelah mulai memahami caranya, saya melanjutkan pengerjaan dengan memasukkan kode HTML, CSS, dan JavaScript sesuai kebutuhan website. Saya juga mulai mengatur tampilan website, seperti warna, ukuran gambar, posisi produk, dan bentuk kotak katalog agar sesuai dengan konsep LAVERA yang sudah saya tentukan.

Selama proses pengerjaan, kendala yang paling sering saya alami adalah pada bagian CSS. Beberapa kali CSS tidak terbaca atau perubahan yang saya buat tidak muncul pada halaman website. Hal tersebut membuat saya harus memeriksa kembali kode yang sudah ditulis. Karena masih belum terlalu memahami penyebabnya, saya beberapa kali meminta bantuan AI untuk menjelaskan dan membantu memperbaiki kesalahan tersebut.

Dari proses pengerjaan ini, saya mendapatkan pengalaman baru dalam membuat website menggunakan HTML, CSS, dan JavaScript. Saya juga menjadi lebih memahami cara menghubungkan beberapa halaman HTML, mengatur tampilan website, serta mencari solusi ketika terjadi kesalahan pada kode. Meskipun masih ada beberapa bagian yang perlu diperbaiki, saya berusaha mengerjakan projek ini secara bertahap sampai website yang dibuat sesuai dengan konsep awal.
